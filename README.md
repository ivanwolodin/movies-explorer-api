# Movies Explorer — API

Backend API for the Movies Explorer application, built with Node.js and Express.

## Technology Stack

- JavaScript (Node.js)
- Express
- MongoDB
- Mongoose

## Getting Started

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run start
```

For development:

```bash
npm run dev
```

## Project Structure

```text
.
├── controllers/   # Request handlers
├── errors/        # Custom error classes and error handlers
├── middlewares/   # Authentication and logging
├── models/        # Database models
├── routes/        # API routes
├── utils/         # Utility functions
└── app.js         # Application entry point
```
